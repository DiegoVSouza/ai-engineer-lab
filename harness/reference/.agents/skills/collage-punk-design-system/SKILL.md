# Collage-punk design system

- Palette: black #0a0a0a, red #e11b22, paper #f0ece4. Nothing else except tints.
- Shapes: skewed/clip-path polygons, paper cards with offset red shadow, torn edges, tape/stickers.
- Type: heavy condensed headings, monospace labels; outline numerals. No trademarked fonts or logos.
- Texture: halftone dots, grain, edge outline pass, velocity ghost.
- Layout: diagonals ≈ 6–8°, but body text stays horizontal and legible.
- Never use ATLUS/Persona assets, characters or fonts; reuse techniques only.
- 3D background: follow `ui-scene-composition` and `threejs-ui-background`.
